# Amazon SDE Interview Prep — 20 Day Topic Map

## 1. Coding / DSA — Highest Priority

Main topics to prepare:

* Arrays
* Strings
* Hash Maps / Hash Sets
* Two Pointers
* Sliding Window
* Prefix Sum
* Linked Lists
* Stacks
* Queues / Deques
* Binary Search
* Trees
* Binary Search Trees
* Heaps / Priority Queues
* Graphs
* BFS
* DFS
* Recursion
* Backtracking
* Intervals
* Greedy
* Dynamic Programming — basic/common patterns
* Trie — basic
* Union Find / DSU — basic
* Time Complexity
* Space Complexity

### Coding Interview Skills

For every problem, practice:

* Understand and clarify the problem
* Explain the brute-force approach
* Find an optimized approach
* Write syntactically correct code
* Handle edge cases
* Test the code manually
* Explain time complexity
* Explain space complexity

1. Coding / DSA
2. Amazon Leadership Principles
3. System Design

# Approximate 20-Day Allocation

* Days 1–10: DSA
* Days 11–14: System Design
* Days 15–16: OOP / LLD
* Days 17–18: CS Fundamentals + C++
* Day 19: Resume + Behavioral
* Day 20: Mock Interview + Final Revision

Leadership Principle stories should be prepared gradually throughout the 20 days instead of leaving everything until Day 19.

---

# Final Goal

By interview day, I should be able to:

* Solve common medium-level DSA problems
* Explain my thinking while coding
* Write clean C++ without relying heavily on an IDE
* Analyze time and space complexity
* Design a scalable backend system at a high level
* Design basic object-oriented systems
* Explain DB, OS, and networking fundamentals
* Answer Amazon behavioral questions using STAR
* Defend every important technical point on my resume
